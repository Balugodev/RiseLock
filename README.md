# RiseLock

RiseLock is a smart alarm web application designed to help users wake up on time through customizable alarms and wake-up challenges. The application provides an interactive alarm experience that makes waking up more engaging and helps users manage their alarm schedules.


Features
- Set and customize alarms
- Display the scheduled alarm time
- Interactive wake-up challenges
- Alarm notification and sound
- User-friendly interface
- Responsive design for different screen sizes
- Simple and easy-to-use controls


Technologies Used
- HTML
- CSS
- JavaScript


Installation / Usage
1. Open the repository and download or clone the project.
2. Open the "index.html" file in a web browser.
3. Set an alarm using the available controls.
4. Follow the wake-up challenge when the alarm activates.
5. Use the application to manage and customize your alarms.
